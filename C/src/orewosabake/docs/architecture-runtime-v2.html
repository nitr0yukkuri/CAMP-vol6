📷

端末内 — React + MediaPipe

Web Workerで頭・尾を検知し、BlazeFaceで顔を確認します。頭・尾の新鮮な検知と顔チェックを通過した静止画だけGemini確認へ進みます。

↓
☁

Cloudflare Worker

画像確認APIとガイドAPIを提供。Durable Object + SQLiteがセッション、利用者別の短時間制限、全体の日次上限を管理し、一時的なGemini障害を限定再試行します。

↓
✦

Google Gemini API

顔チェックを通過した静止画1枚をWorker経由で送り、見える範囲を参考確認します。不確実な結果は不確実と表示し、ガイドは自動で進みません。

⌘

開発・公開

Node.js APIはローカル開発用。GitHub ActionsからCloudflare Workerをデプロイします。

顔を検知した場合や人物チェックを利用できない場合は画像を送りません。顔検知の見逃しを完全に防ぐ保証ではありません。
