# Salmon face-detection demo image

This is a synthetic, AI-generated salmon image intended only as a visual sample for manually checking the app's MediaPipe face-detection guard.

- It is not a real fish photo, a training/evaluation sample, or a fish-preparation instruction.
- The image is not loaded or analyzed automatically by the app.
- Whether MediaPipe reports a face is unverified and can vary by browser, device, resize, and model version.
- The public file exists so it can be opened directly or shown to a camera as a demo target.

Use the image only to investigate false-positive behavior. Do not treat its detector output as a model-quality result.
