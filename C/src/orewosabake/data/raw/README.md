# 公開データのローカルコピー

以下は調査用に取得した公開データです。生画像・アーカイブは `data/.gitignore` でGit対象外にしています。

## Mendeley: Dataset for Detecting Head and Tail of Fish

- 取得元: <https://data.mendeley.com/datasets/7m2yzmpcft/1>
- DOI: `10.17632/7m2yzmpcft.1`
- 公開ページのライセンス表示: CC BY 4.0
- ローカルアーカイブ: `mendeley-head-tail/mendeley-head-tail-v1.zip`
- 展開先: `mendeley-head-tail/extracted/`
- ローカルで確認したアーカイブサイズ: 13,476,057 bytes

再配布・公開前に、取得元の現在のライセンス表示と帰属表示条件を確認してください。

- ライセンス表示: CC BY 4.0
- ローカルファイル: `autofish-preview/metadata.csv`
- 画像サンプル: この作業環境では取得できていません。取得を試しましたが、ファイル配信先の名前解決／リダイレクト取得に失敗しました。
