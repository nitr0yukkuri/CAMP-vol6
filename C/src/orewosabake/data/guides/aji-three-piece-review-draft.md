# アジの三枚おろし — 経験者レビュー待ちのドラフト

**状態: DRAFT / 未レビュー / アプリの実用ガイドとして未公開**

この文書は、アジ1魚種の工程、画面チェック、停止・戻り方をレビューできる形に整理したものです。公開資料を元にした初稿であり、調理経験者による包丁操作・左右の向き・安全上の確認が済んでいません。確認者の氏名、経験、レビュー日が記録されるまでは、この手順をアプリで案内しません。現在のAPIも`guideAvailability: not_configured`で、実用ガイド生成は未接続です。

## 対象と範囲

- 対象: 1尾のマアジを、頭・内臓を除き、左右の身と中骨に分け、腹骨を整える三枚おろしの練習。
- 対象外: 活魚の締め、刺身・生食の安全判断、寄生虫判定、骨の完全除去保証、他魚種への手順流用。
- 操作方針: 画面上の認識は候補に限る。利用者が工程を確認しない限り自動進行しない。頭・尾の未検出は切除済みの証拠にしない。
- 実施前レビュー: 初心者が包丁を使う場合の見守り要否、各カットの言い回しと撮影角度、魚の向き、鋭い部位の扱いを経験者が確認する。

## 画面に載せる停止ルール

1. まな板や魚が動く、手元がカメラ外、刃先が見えない、画面が曇る、または工程を判断できない場合は**停止**し、包丁を置いてから置き直す。
2. 手指を切った、痛み・出血がある、魚の鮮度や食用可否に疑問がある場合は作業を止め、アプリの案内を続けず、人に確認する。
3. 工程が合わないと思ったら**前へ進まず**、最後に確認できた状態へ戻る。アプリは画像だけで完了判定しない。
4. 身が骨から外れたか判断できない場合は、追加で刃を動かすよう促さず、画像を撮り直すか経験者に確認する。

停止ルールと包丁の安全表現は、経験者レビューとユーザビリティ確認を要します。

## ガイド工程案

| ID | 工程・利用者に見せる要点 | 利用者の確認項目 | 停止・戻り方 |
| --- | --- | --- | --- |
| `prepare` | 魚種がアジであること、目的が三枚おろしの練習であることを確認する。まな板・魚を安定させ、カメラで魚全体を映す。 | 魚全体、頭・尾、手元が見える。魚が動かない。 | 魚やまな板が動く、手元が画面外なら撮影位置を直してこの工程から確認し直す。 |
| `remove_zeigo` | ぜいごを取る工程。アジの尾に近い硬い部分が映る向きへ置く。具体的な刃の向きと手の位置は経験者がレビューしてから表示する。 | ぜいごが取れたか、魚が安定しているかを人が見る。 | ぜいごの位置や刃先が見えない場合は止めて、向きを整える。 |
| `remove_head` | 胸びれの付け根付近で頭を外す工程。カットの角度・左右の向きはレビュー後に図と合わせる。 | 頭が外れたことを目視で確認する。画面に頭がないだけでは確認済みにしない。 | 手や包丁で隠れている、画面外の場合は`unknown`として撮り直す。切除状態をAIが推測して進めない。 |
| `remove_guts` | 腹側を開いて内臓を取り出し、腹腔を洗って水気を取る工程。洗浄方法は用途に合わせてレビューする。 | 内臓が取り出されたか、腹腔内を人が確認できるか。 | 中身が隠れている・残りが判断できない場合は止め、経験者に見せる。 |
| `fillet_first_side` | 中骨に沿って片側の身を外す工程。刃を骨に沿わせる説明とカメラ位置をレビューする。 | 外した側の身と中骨が見え、骨に沿って分かれていることを人が確認する。 | 魚が滑る、刃先が見えない、どちら側か不明なら止めて`prepare`へ戻る。 |
| `fillet_second_side` | 魚を返して反対側の身を外す工程。向きを変えた後、頭側と尾側を人が確認する。 | 左右の身2枚と中骨の計3つに分かれたことを人が見る。 | 向きの混乱や見えない骨があれば停止し、直前工程へ戻る。 |
| `trim_and_check` | 腹骨を整え、身に骨が残っていないか人が確認する。皮引きや刺身への用途展開はこのドラフトでは扱わない。 | 2枚の身、中骨、腹骨の状態が見える。小骨の確認は人が行う。 | 骨が残っていないか判断できない場合は「完了」とせず、経験者へ確認する。 |

各工程の文章は[千葉県「アジのおろし方」](https://www.pref.chiba.lg.jp/suisan/sakana/oroshikata/aji.html)と[三重県漁業協同組合連合会「アジのさばき方」](https://www.miegyoren.or.jp/gourmet/howto/howto_aji/)の手順を参考に要約し、画面に必要な確認・停止点を付けた案です。両資料で工程や説明の細部が異なる可能性があるため、レビュー担当者が採用する一つの標準手順を決めます。
