## Safariでの確認手順

1. デプロイ済みの`https://` URLをSafariで開き、読み込み後に画面を更新して最新版を取得します。URL・証明書エラーがあればカメラ確認に進みません。
2. 「研究用データを撮る」を開き、カメラを起動します。Safariのカメラ許可ダイアログが出るか、拒否後に設定から許可し直せるか記録します。
3. 背面カメラの映像が表示されることを確認します。モデル読み込み中・準備完了・エラー表示を記録します。モデルとWASMの取得状況を確認できる場合は、Safari Web InspectorのNetworkで`head-tail.tflite`と`wasm`のURL、HTTP status、転送量、所要時間も記録します。
4. 画面を縦・横に回し、案内表示、プレビューの向き、検出枠の位置が映像に合うかを確認します。スクロールやシステムバーで撮影ボタンが隠れないことも見ます。
5. 魚の静止画を1枚撮り、頭と尾の枠を別々にドラッグします。枠のサイズ・場所、指での描画、誤操作時の消去を確認します。AI候補が教師枠へ自動コピーされていないことを確認してからJPGを保存します。
6. 「CSVラベル一覧を保存」を押し、写真とCSVをファイルアプリで再度開きます。CSVのファイル名と`frame_path`が一致し、手描き枠が正規化座標として保存され、`ai_observation_json`とは別列になっていることを確認します。
7. カメラ停止後に再起動し、Safariを一度バックグラウンドにして戻った場合も確認します。映像・推論が止まり、再開操作後に復帰するか、権限エラーが分かる表示になるか記録します。
8. 10回ほど画面表示の更新を観察し、検出更新間隔と、撮影から枠付け画面までの応答を記録します。目視計測であることを明記し、測れなかった値は空欄にします。
